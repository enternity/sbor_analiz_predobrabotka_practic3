# Практическая / Лабораторная работа №3
**Дисциплина:** Сбор, анализ и предобработка данных  
**Тема:** Визуализация данных (Pandas, Matplotlib, Seaborn)

## Описание проекта
Исследование и визуализация набора данных об успеваемости студентов (`StudentsPerformance.csv`) с помощью библиотек Python.

## Файлы в репозитории
* `lab03.ipynb` — интерактивный блокнот Jupyter Notebook с кодом, расчётами и построенными графиками.
* `StudentsPerformance.csv` — исходный датасет (1000 записей, 8 признаков).

## Основные результаты работы
1. **Pandas**: построены столбчатая диаграмма уровня образования родителей (`parental level of education`), круговая диаграмма этнических групп (`race/ethnicity`) и общие гистограммы распределения оценок по трём предметам.
2. **Matplotlib (`subplots 3x2`)**: построена сетка из 6 разнотипных графиков (тригонометрические функции, горизонтальный `boxplot`, комбинированный график столбцов и тренда, текстовый блок, 3D-диаграмма рассеяния и круговая диаграмма для выборки юношей `gender == 'male'`). По методу межквартильного размаха ($IQR = 20.0$) выявлено **8 выбросов** по математике с оценками ниже `27.0` баллов.
3. **Seaborn**: построены матрицы попарных распределений `pairplot` (с гистограммами и с ядерной оценкой плотности `KDE` по признаку пола `gender`) и тепловая карта корреляций (`heatmap`). Установлена сильная положительная корреляция между результатами по чтению и письму ($r = 0.955$).
